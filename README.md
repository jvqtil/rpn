# rpn
This is a [Reverse Polish Notation](https://en.wikipedia.org/wiki/Reverse_Polish_notation/) calculator.

[The original](https://breder.org/rpn-calculator/). 
I took the code as starting point and did some stuff with it - check TODO.md for the complete list.

## Building
Just do `make`

## Usage

### Supported operations
```
ADD, SUB, MUL, DIV
REM, POW, HYP, AT2
SQT, CBT, ABS, NEG
SIN, COS, TAN, ASN
ACS, ATN, SNH, CSH
TNH, EXP, LOG, L10
LG2, CEL, FLR, RND
PI,  EUL, CLR, DRP
DUP, SWP
```
